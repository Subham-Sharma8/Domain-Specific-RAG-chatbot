# Final Submission Checklist

Use this checklist before submitting:

- [ ] `app.py` opens the Streamlit interface.
- [ ] `pip install -r requirements.txt` completes successfully.
- [ ] `.env` contains a valid `GROQ_API_KEY` locally and is NOT uploaded.
- [ ] At least one PDF can be uploaded.
- [ ] Documents can be processed.
- [ ] Questions return grounded answers.
- [ ] Source document and page are displayed.
- [ ] An unavailable question returns the required fallback.
- [ ] `pytest -q` passes.
- [ ] README is included.
- [ ] Architecture diagram is included.
- [ ] 15-question testing sheet is included.
- [ ] Project report is included.
- [ ] Viva questions are included.
- [ ] Demo video script is included.
- [ ] GitHub repository is created and the repository URL is ready for submission.
